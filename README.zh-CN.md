# NoteMark

[English](README.md) | 简体中文

在 Apple 备忘录中直接写 Markdown，NoteMark 会将标记转换为备忘录原生格式。

**版本：0.2.0 测试版** · macOS 14+ · 当前安装包适用于 Apple Silicon

## 安装与权限配置

1. 解压安装包，先将 **NoteMark.app** 移到 **应用程序（Applications）**，再配置权限。自行编译请参考[编译说明](#编译)。
2. 打开 NoteMark，使用说明窗口会实时显示两项权限的 ✓ 或 ✗。点击第一项的 **打开设置…**，在 **系统设置 → 隐私与安全性 → 辅助功能**（macOS 27 中为 **隐私与安全 → 设备控制和数据访问**）中开启 **NoteMark**。列表中没有时，点击 **+**，从应用程序中添加。
3. 权限就绪后自动开启转换，通常在 2 秒内生效。如果仍无法识别输入，点击 **输入监控** 一项的 **打开设置…** 并开启 NoteMark，再点击 **重新打开 NoteMark**。
4. 打开 **Apple 备忘录**，新建测试笔记，输入 `-` 再按 **空格**，应转换为圆点列表。

权限需要在系统设置中手动授予，无需完全磁盘访问权限。界面语言跟随系统，支持简体中文、繁体中文和英文。使用说明窗口只在首次使用、无法转换，或从访达再次打开 NoteMark 时弹出，其余时间只显示在菜单栏。

## 使用方法

- 在备忘录正文中输入，并保持备忘录位于前台。段落标记要在空行行首输入，再按 **空格**。
- 已有文字也能转为圆点列表：将光标放到段落第一个字前，输入 `-` 或 `*`，再按 **空格**。原文字会保留，整段变成原生 `•` 列表。
- 输入 `[]` 后按 **空格**，即可开始输入待办内容；也可以加在已有段落的文字前。按 **回车** 创建下一项。
- 空行输入 `/` 打开命令菜单。输入 `/h2` 或 `/code` 搜索，用 **↑ / ↓** 选择，按 **回车 / Tab** 执行。**Esc** 关闭并保留文字，也可点击命令。
- 写完 `**粗体**` 等行内标记后，按 **空格或回车** 转换。中文正文里标记前后不需要空格，例如 `这是**重点**`。
- 想保留标记原文：先输入反斜杠（输入 `\#` 再按 **空格** 得到 `#`，空格只用来确认、不会输入），或按 **Shift+空格**。转换后立即按 **⌘Z**，这一段的标记也会保留原文，直到你按回车、点击、删除或移到其他段落；之后输入的行内样式仍会转换。切换 App 不会解除。
- 转换无法完成时（例如账户不支持核对清单），光标旁会短暂显示原因。
- NoteMark 切换段落格式后（标题、引用、代码块或列表），在空段落按 **退格**、**向前删除**、**Esc** 或 **Ctrl+K / Ctrl+H / Ctrl+D** 即可恢复正文。在同一段落输入文字后再删空，也能再次按上述按键恢复。代码格式按回车换行、退格返回上一代码行后仍保持跟踪。代码取消会检查整段连续代码，并使用段落换行符的格式识别中文及 emoji 字体回退；未知边界不会被当成正文而提前取消。退格和 Ctrl+K/H/D 会继续原生删除文字与换行；代码只剩空行且光标到达删除方向上的边界时，就在当前光标处恢复正文，不再带着空块合并到旁边正文。删除中途不选中整块或跳到块尾。Esc 可将整段只剩空行的代码恢复正文，保留空行。切换 App、点击或更新程序后，已有等宽段落会重新识别；已有空代码行也能直接取消。其他格式离开段落后结束跟踪。鼠标点击、切换 App 或手动修改格式也会结束跟踪。仍有文字时，可按 **⌘⇧B** 切回正文。
- 菜单栏 NoteMark 图标和菜单中 NoteMark 标题下方的一行会显示当前状态（转换已开启、已暂停、需要权限或无法监听输入）；如果系统停用了输入监听，会自动弹出使用说明。点击图标可 **暂停 Markdown 转换**、**恢复 Markdown 转换**、打开 **设置…** 或 **退出 NoteMark**。手动暂停仅保持到本次退出；下次启动会在权限就绪后自动开启。
- **设置**（⌘,）可以单独开关每一类转换，选择 `-` 生成项目符号列表还是短划线列表，以及登录时打开 NoteMark。
- **新插入的图片显示为小尺寸**（在菜单栏菜单和设置中，默认关闭）：粘贴或插入图片后，NoteMark 会在备忘录中执行 **显示 → 附件视图 → 全部设为小尺寸**。备忘录没有“新图片默认大小”的设置，所以它会作用于这条备忘录中的所有附件，包括你调大过的。
- 备忘录自带的 **编辑 → 替换** 会在输入时改写标记：“智能破折号”把 `---` 换成 `—`，“智能列表”在 `\-` 之后仍会把 `- ` 变成列表，“智能标签”把 `#文字` 变成标签。NoteMark 会通过这个菜单在备忘录中关闭智能破折号和智能列表（智能标签只在你选择时关闭）；在设置中关掉对应开关，会在备忘录中重新打开该选项。
- 按 **⌘Z** 撤销。段落转换可能需要撤销两次。

## 支持的语法

在空行行首输入标记，再按 **空格**。`-`、`*`、`[]` 和 `[ ]` 也可加在已有段落的文字前。

| 输入 | 效果 |
| --- | --- |
| `#` / `##` / `###` | 标题 / 小标题 / 次级标题（`####` 至 `######` 也生成次级标题） |
| `-` / `*` | 圆点列表 `•`（可在设置中让 `-` 生成短划线列表） |
| `1.` | 编号列表 |
| `[]` / `[ ]` / `- [ ]` | 待办清单（也支持 `［］`、`【】`） |
| `>` | 引用 |
| 三个反引号 | 等宽代码段落，再次输入退出 |
| `---` / `***` / `___` | 原生分隔线，按 **空格** 或 **回车**（macOS 27 及以上；更早的系统保留原文） |

也支持全角和中文标点：`＃`、`＞` 或 `》`、`＊`、`－`、`１．` 或 `1。`，以及代码块的 `···` 或 `｀｀｀`。

三个反引号后加 `swift` 等语言名，再按 **回车**，也可开始代码段落；不提供语法高亮。

行内标记：`**粗体**`、`*斜体*`、`***粗斜体***`、`__粗体__`、`_斜体_`、`` `代码` ``、`~~删除线~~`、`[链接](https://example.com)`。

Slash 命令：`/h1`、`/h2`、`/h3`、`/body`、`/code`、`/quote`、`/checklist`、`/bullets`、`/dashed`、`/numbered`、`/divider`（macOS 27 及以上），以及 `/date`（按首选语言的格式插入今天的日期）。菜单搜索会匹配命令名称、说明、备忘录自己的叫法（如“核对清单”“块引用”）、中英文别名，以及拼音或拼音首字母（`/bt` 找到“标题”）；例如“列表”会显示全部列表类型，“序号列表”会匹配编号列表。全角 `／` 也可打开菜单。首次在空行输入 `/` 会展示完整菜单。继续输入时仅展示匹配结果，例如 `/标题`、`/题`；输入空格或无匹配内容会关闭菜单，退格回到单独 `/` 也不会重新打开。继续输入匹配文字可重新展示；有效名称末尾的空格不影响匹配。用回车、Tab 或点击执行。中文输入法组词时，空格、回车、方向键和 Esc 交给输入法，确认候选词后继续搜索，再按回车执行。

## 无法转换时

- 检查 **应用程序** 中的 NoteMark 是否已授权，再退出并重新打开。更换签名身份时可能需要再次授权。
- 已暂停时点击菜单栏中的 **恢复 Markdown 转换**；连接失败时点击 **重试输入连接**。
- 某类标记不再转换时，检查 **设置** 中对应的开关是否打开。
- 待办转换失败时，检查备忘录 **格式 → 核对清单** 是否可用，也可按 **⌘⇧L** 测试（[Apple 快捷键说明](https://support.apple.com/guide/notes/apd46c25187e/mac)）。原生命令不可用时，NoteMark 会保留标记。
- 先在新建、未锁定笔记的空行试用。搜索框、选中文字和代码段落不会触发普通 Markdown 转换。

## 注意事项

- 这是本地菜单栏辅助程序，不保存或上传笔记内容，不修改备忘录数据库。
- 段落使用备忘录原生样式，行内格式保留当前字号。行内转换会短暂使用剪贴板，并标记为临时内容，剪贴板管理工具会忽略它；备忘录完成粘贴后，若未复制新内容，会恢复原内容。转换前会保存来源 App 当时能提供的全部格式；文件承诺等延迟提供的内容无法恢复。
- 暂不支持整篇转换、嵌套 Markdown 和 Markdown 图片插入；包含图片的当前段落会跳过转换。
- 空代码段取消最多检查光标两侧各 4096 个 UTF-16 单元；无法确认整段边界时，保留原生按键操作。
- 给已有文字加圆点列表或待办清单时，最多检查光标后的 512 个 UTF-16 单元；无法在此范围内确认段落结束时，会跳过转换。
- 已在 macOS 27.0.1 / Apple Silicon 编译；真实备忘录输入、输入法和快速连续输入仍需手动验证。详见[验证说明](VALIDATION.zh-CN.md)。

## 更新

退出 NoteMark，使用相同签名身份的新版本替换 **/Applications/NoteMark.app**。本地编译时运行：

```sh
sh scripts/build.sh
sh scripts/install.sh
```

安装脚本会检查签名兼容性、备份旧 App、退出程序，在原路径替换并重新打开。只检查、不安装时，运行 `sh scripts/install.sh --check`。备份保存在 `dist/installed-backups`，默认保留最近 10 份；可用 `NOTEMARK_BACKUP_LIMIT` 调整数量，设为 `0` 则全部保留。

同签名身份的兼容版本应能沿用权限。首次从旧的 ad-hoc 签名版本换成证书签名版本，仍需重新授权一次。后续请保持签名身份和 Bundle ID 不变。详见 [Apple 对代码身份的说明](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。

目前提供本地更新脚本，尚未加入 App 内下载更新。

## 编译

需要 macOS 14+ 和 Xcode/Swift 工具链，无第三方依赖。

先配置一次签名身份。从第一条命令输出中复制证书的 40 位 SHA-1：

```sh
security find-identity -v -p codesigning
sh scripts/configure-signing.sh CERTIFICATE_SHA1
```

选择保存在 Git 忽略的 `.signing-identity` 中，证书和私钥仍在钥匙串。macOS 可能要求允许 `codesign` 使用私钥，请在系统钥匙串弹窗中授权。本机开发可使用 Apple Development；公开分发需要 [Developer ID 签名和公证](https://developer.apple.com/help/account/certificates/create-developer-id-certificates/)。

```sh
sh scripts/build.sh
```

构建会先运行 `swift test` 和 `scripts/check-localization.swift`；设置 `NOTEMARK_SKIP_TESTS=1` 可跳过测试。`Packaging/Resources` 中的翻译和应用图标会复制进 App；运行 `swift scripts/make-icon.swift Packaging/Resources/AppIcon.icns` 可重新绘制应用图标（原创图案：带黄色加号的便笺，不是苹果备忘录的官方图标）。输出：`dist/NoteMark.app` 和 `dist/NoteMark-<版本号>.zip`。版本号和 Bundle ID 来自 `Packaging/app.env`，`Packaging/Info.plist` 是 App 属性列表模板。构建使用已配置的证书；未配置时会报错。临时 ad-hoc 测试构建可运行 `NOTEMARK_SIGNING_IDENTITY=- sh scripts/build.sh`，安装脚本会拒绝此类构建。

```sh
dist/NoteMark.app/Contents/MacOS/NoteMark --self-check
dist/NoteMark.app/Contents/MacOS/NoteMark --diagnose
```

`--self-check` 检查本地规则；`--diagnose` 输出系统版本、本进程权限及 App 最后记录的运行状态，包括最近一次空格或回车没有匹配规则的原因（只含长度和开关值）。本地状态文件不记录笔记文字或按键内容；退出后状态可能过时。如需在每次编辑后额外记录段落跟踪状态，运行 `defaults write dev.local.notemark NoteMarkVerboseDiagnostics -bool YES` 并重启 NoteMark；这会在输入时增加辅助功能读取，排查完毕后用 `defaults delete dev.local.notemark NoteMarkVerboseDiagnostics` 关闭。

构建产物和本地配置已由 Git 忽略。

代码结构：`Sources/NoteMarkCore` 是纯 Swift 规则层（Markdown、Slash、段落和按键分类），全部有单元测试。`Sources/NoteMark` 是菜单栏 App：`App`（应用委托、命令行模式与自检、界面文字）、`Input`（事件监听、输入暂存、键盘布局、合成按键、剪贴板）、`Accessibility`（备忘录编辑器快照与菜单命令）、`Conversion`（事件分发、Slash 菜单、段落跟踪、编辑）、`Diagnostics` 和 `UI`。App 以 Swift 6 语言模式和主线程隔离编译。
